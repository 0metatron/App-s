# cesar.apps

Portfólio do Cesar: apps e robôs sob medida (Macapá, AP).

- `index.html`: portfólio
- `simulador.html`: simulador de motos (demonstração)
- `robo.html`: robô de pedidos no WhatsApp (demonstração)
- `painel-servicos.html`: painel para empresa de serviços terceirizados, com login e banco Supabase (demonstração em `#demo`)
